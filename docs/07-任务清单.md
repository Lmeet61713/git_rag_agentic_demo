## 本轮更新

- 接入 ONNX `bge-small-zh-v1.5`、Chroma、LangGraph 状态流。
- 新增项目级技术栈摘要、并集混合检索、置信度过滤。
- 新增 `general_chat` 输出越界校验，以及检索后重排、LLM 相关性校验与多轮重试。
- DeepSeek 作为常驻模型，调用失败时自动降级到本地 Ollama 保底模型。
- 新增任意公开 GitHub 仓库 URL 导入。
- SSE 改为逐 token 流式，聊天页支持 Markdown 与来源摘要。
- 左侧边栏显示当前模型并支持随时切换。
- 后端 47 项、前端 7 项测试通过，前端生产构建通过。
- 聊天消息持久化工具与模式，历史会话重新加载后保留标签。
- 长期记忆改为中文分词召回并按项目隔离，会话摘要去重更新。
- 显式项目检索不再跨项目兜底，图片/文档专用检索不降级为其他类型。
- 图片兜底描述包含完整相对路径，来源链接支持 URL 编码。
- 顶部导航布局、可折叠聊天会话栏与 lucide 品牌标识。
- 新增 `repo_brief` 仓库列表工具，口语化项目介绍与语言级项目摘要检索。
- 修复 `repo_brief` 误报“没有仓库”，LLM 选中该工具时直接列出仓库；会话列表增强当前项高亮。
- 新增 Tavily 联网搜索工具，API Key 加密存入后端，无本地保底、失败明确报错。
- 路由双重校验：只有明确仓库上下文才触发 `repo_brief`/`project_intro`，日常问题走通用闲聊或联网搜索；联网结果默认折叠。
- 后端 63 项、前端 9 项测试通过，前端生产构建通过。
- 真实数据验证：显式项目图片检索、项目概述、长期记忆中文召回均通过；真实模型问答受 DeepSeek 出网与 Ollama 服务状态影响，待浏览器验收。
- 检索分析：见 [11-检索能力问题分析.md](11-检索能力问题分析.md)。
