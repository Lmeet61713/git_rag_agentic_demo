## 1. 总体验收流程

端到端场景：

```text
GitHub 登录
→ 查看仓库列表
→ 选择仓库入库
→ 等待索引完成
→ Agent 问答
→ 查看来源和图片预览
```

只有该场景在真实浏览器中完整跑通，阶段 10 才算通过。

## 5. 验收记录模板

每次验收记录建议包含：

| 项目 | 内容 |
|------|------|
| 验收时间 | 2026-08-04 |
| 验收人 | 使用者 / Codex |
| 场景 | 登录、入库、问答、图片检索等 |
| 操作步骤 | 实际点击或 API 调用 |
| 期望结果 | 来自本文档对应阶段 |
| 实际结果 | 通过 / 失败 |
| 日志或截图 | 文件路径 |
| 结论 | 是否进入下一阶段 |
