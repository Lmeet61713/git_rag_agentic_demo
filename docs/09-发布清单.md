# Git 发布清单

> 状态：最新  
> 最近更新：2026-08-04  
> 用途：上传 MyAgentic 到 GitHub 前的检查、清理与提交步骤。

## 1. 发布前必须确认

以下内容**不能提交**到 Git：

| 内容 | 原因 |
|------|------|
| `.env` | 包含 GitHub Client Secret、会话密钥、模型 API Key |
| `data/` | 本地 SQLite、仓库镜像、图片描述缓存、运行日志 |
| `storage/` | Chroma 向量库 |
| `.venv/` | 虚拟环境 |
| `node_modules/` | 前端依赖 |
| `frontend/dist/` | 构建产物 |
| `*.log` | 本地运行日志 |
| `.pytest_cache/`、`.ruff_cache/`、`.uv-cache/` | 测试与工具缓存 |
| `img.png`、`img_1.png`、`images/` | 临时截图，非项目资产 |

项目根目录的 `.gitignore` 已覆盖上述内容。发布前仍建议用 `git status` 人工确认。

## 3. 首次上传步骤

项目当前还没有初始化 Git 仓库，可按以下步骤操作：

```powershell
cd E:\mmmmmmmmmmmmmmmm\MyAgentic
git init
git add .
git status
```

检查 `git status` 中不包含：

- `.env`
- `data/`
- `storage/`
- `.venv/`
- `node_modules/`
- `frontend/dist/`
- 任何 `.log`

确认后提交：

```powershell
git commit -m "feat: MyAgentic local GitHub RAG MVP"
```

然后在 GitHub 新建仓库，并关联远程地址：

```powershell
git remote add origin https://github.com/<你的用户名>/MyAgentic.git
git push -u origin main
```

## 7. 已知注意事项

- 后端必须能访问 GitHub，否则 OAuth 回调换 token 会失败。
- 8000 端口只能启动一个后端进程，避免浏览器访问到旧代码。
- 前端统一使用 `http://127.0.0.1:5173`，不要使用 `localhost`。
- `.env.example` 只放变量模板，不放真实密钥。
- Chroma collection 的向量维度在初始化后不可修改，接入 ONNX 前先确认维度。
